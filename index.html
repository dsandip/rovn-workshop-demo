How this page got here

  1. Issue opened — a GitHub issue kicks off the work and (via the bridge) spins up a PromptQL bot.
  2. Branch + AI implementation — the bot writes the change on a feature branch.
  3. Tests — CI validates the change before a human ever looks.
  4. Pull request — the bot opens a PR describing what and why.
  5. Human approval — a reviewer approves. Nothing ships without this gate.
  6. Merge → deploy — merge to main triggers the Pages deploy that published this exact page.
  7. Monitor — the loop closes; the next issue starts it again.
